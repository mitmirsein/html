핵심 개요

코딩이나 복잡한 설정 파일(SOUL.md, MEMORY.md)을 직접 다루지 않고도 내 컴퓨터의 문서와 자료를 함께 처리하는 나만의 AI 봇 팀을 만들 수 있습니다. 가장 간단하고 정밀한 방법은 1호 봇으로 '비서실장(총괄 지휘) 봇' 하나만 먼저 만든 뒤, 내 작업 공간 분석부터 산하 전문 봇 설계·생성 제안·세부 세팅까지 통째로 맡기는 것입니다.

1. 왜 "비서실장 1호 봇"부터 만들면 간단한가요?

이유 1

처음 직접 만들 봇은 단 1개뿐입니다

비서실장 봇(예: maestro, chief) 하나만 먼저 만들어 두면, 이후 필요한 전문 봇들은 비서실장이 채팅창에 생성 제안 카드(Create bot)로 올려 줍니다. 사용자는 제안 내용을 보고 버튼만 클릭하면 됩니다.

이유 2

내 작업 공간을 먼저 파악해 맞춤 팀을 설계합니다

비서실장이 내 컴퓨터의 자료 폴더와 노트 보관함(Obsidian 볼트, 문서 폴더 등)을 읽기 전용으로 먼저 훑어 평소 작업 흐름과 문체를 파악한 뒤, 기성 템플릿이 아니라 내 업무에 꼭 맞는 팀 편제를 제안합니다.

이유 3

창구가 하나로 통일됩니다

봇이 늘어나도 "이 일을 어느 봇에게 맡겨야 하지?" 고민할 필요 없이 비서실장에게 말하면, 작업 성격을 판단해 적합한 전문 봇에 분배하고 진행 현황과 검수 결과를 한눈에 보고해 줍니다.

이유 4

필요할 때 자연스럽게 확장할 수 있습니다

처음에는 2~3개 핵심 봇으로 가볍게 시작했다가, 새로운 반복 업무가 생기면 비서실장에게 말해 새 전문 봇을 제안받고 기존 팀 규칙에 바로 연결할 수 있습니다.

2. 시작 전 준비물 (딱 4가지)

번호 준비 항목 설명
1 Orca 앱 + AI 계정 로그인 컴퓨터(Mac)에 Orca를 설치하고 사용할 AI 에이전트(Antigravity, Claude, Codex 중 1개 이상)에 로그인합니다.
2 내 작업 폴더 경로 참고 자료(PDF·문헌), 내 원본 문서·노트, AI 결과물을 저장할 작업대 폴더의 위치를 미리 확인해 둡니다.
3 원하는 업무 영역 메모 (3~5줄) 전문 용어 없이 "자료 조사·요약, 초안 작성 협업, 원고 비판적 검수, 문서 정리"처럼 맡기고 싶은 일을 편하게 적습니다.
4 절대 금지선 메모 (2~3줄) 예: "기존 원본 폴더는 절대 덮어쓰지 말 것", "확인되지 않은 출처나 사실을 지어내지 말 것", "허락 없이 메일 발송·외부 공유 금지"
TIP · Google 연동 안내

Google Drive, Docs, Gmail, Calendar 연동이 필요하면 사용할 Google 계정만 정해 두시면 됩니다. 연결 과정도 나중에 비서실장 채팅에서 "Google 연결해 줘"라고 말하면 나오는 안내 카드를 따라 클릭만 하면 완료됩니다.

3. 비서실장 1호로 시작하는 4단계 구축 절차

1단계

1호 봇 '비서실장' 하나만 생성하기

  • Orca에서 첫 번째 봇을 단 하나만 생성합니다(이름 예: maestro 또는 chief).
  • 이 봇의 역할은 모든 일을 직접 처리하는 만능 봇이 아니라, 내 작업 공간을 파악해 산하 전문 봇 팀을 설계·세팅하고 작업 판단·분배·품질 점검을 총괄하는 비서실장으로 정합니다.
2단계

비서실장에게 "작업 공간 조사 + 팀 청사진 제안" 맡기기

비서실장의 Home Chat이 열리면 아래 4장의 복사-붙여넣기 프롬프트를 보냅니다. 그러면 비서실장이 다음 작업을 자동으로 수행합니다.

  • Orca 봇의 협업 방식과 기능 파악
  • 내 문서 폴더와 볼트를 읽기 전용으로 훑어 폴더 구조와 평소 작업 스타일 파악
  • 내 요청에 맞춘 산하 봇 편제표(각 봇 이름, 전담 역할, 추천 AI 모델과 추론 강도, 협업 순서, 폴더별 읽기·쓰기 권한 경계) 제안
3단계

제안서 승인 후, 생성 카드에서 클릭만 하기

비서실장이 가져온 청사진에서 아래 네 가지만 확인하고 수정할 점을 말로 지시합니다.

  • 역할 분담: 내 평소 업무 흐름에 꼭 맞는 봇들로 구성되었는가?
  • 모델과 추론 강도 배분: 단순 정리·분류·요약 봇은 가볍고 빠른 모델과 낮은 추론 강도로, 깊은 분석·비판적 검수(레드팀) 봇은 상위 모델과 높은 추론 강도로 속도와 비용 균형이 맞게 제안되었는가?
  • 원본 보호 구역: 내 참고 자료와 기존 원본 문서 폴더는 읽기 전용으로 보호되고, AI 결과물은 별도 작업대 폴더에만 저장되는가?
  • 사용자 판단 구간 보호: 내가 직접 깊이 생각하고 결정해야 하는 핵심 업무는 AI가 먼저 완성본을 대필하지 않고 질문과 대화로 돕도록 설계되었는가?

제안이 마음에 들면 "승인한다. 제안한 산하 봇들을 생성 카드로 올려 줘"라고 말합니다. 채팅창에 각 봇의 제안 카드가 뜨면 추천받은 모델과 추론 강도를 확인한 뒤 Create bot 버튼을 눌러 생성합니다.

4단계

산하 봇 세부 세팅 일괄 위임 및 점검

모든 산하 봇 생성이 끝나면 비서실장에게 "방금 만든 산하 봇들에 승인한 설계대로 SOUL.md, MEMORY.md, 폴더 권한, 협업 편제표를 일괄 세팅하고 전체 점검 결과를 보고해 줘"라고 지시합니다.

  • 비서실장이 각 봇의 홈 폴더(~/.orca/bots/<봇이름>/)에 맞춤 규칙과 장기 기억 파일을 작성하고 연결합니다.
  • 마지막으로 작은 실제 과제 1건(예: PDF 문서 1편 요약 또는 초안 검토)을 시범 가동해 보고 어색한 부분만 말로 다듬으면 구축이 끝납니다.

4. 비서실장 1호 봇에 붙여 넣는 "첫 지시 프롬프트"

비서실장 봇을 생성한 뒤, 아래 문구의 [대괄호] 부분만 채워 첫 메시지로 보내시면 조사부터 설계·세팅까지 일관되게 진행됩니다.

첫 지시 프롬프트 (복사용 원문) 복사 후 [대괄호] 항목만 내 폴더 경로와 업무 내용으로 바꿔 전송합니다. 
너는 앞으로 나의 산하 전문 봇 팀을 설계하고, 작업 판단·분배·품질 점검·유지보수를 총괄하는 비서실장(Chief of Staff) 봇이야.
내가 설정 파일을 직접 작성하지 않고, 너에게 설계와 세부 세팅을 맡기고 싶어.

[내 작업 공간(폴더·볼트) 경로]
- 참고 자료 폴더(읽기 전용): [예: /Users/이름/Documents/Library]
- 내 원본 문서·노트 폴더(원본 보호): [예: /Users/이름/Documents/Workspace]
- AI 결과물을 저장할 작업대 폴더: [예: /Users/이름/Documents/AI_Output]

[내가 사용 중인 AI 구독 / 모델]
- 예: Claude, Antigravity, Codex 중 보유한 계정과 모델 기재

[내가 만들고 싶은 팀과 업무]
- 예: 자료 조사 및 요약, 문서 초안 협업, 결과물 비판적 검수, 최종 정리 및 배포 등
- (원하는 업무 영역을 3~5줄로 편하게 작성)

[절대 지켜야 할 원칙]
1. 너(비서실장)는 지휘와 점검만 맡고, 산하 전문 봇이 생긴 뒤에는 실무 문서를 직접 대신 집필하지 말 것
2. 내 기존 원본 폴더와 참고 자료 폴더는 절대 덮어쓰거나 삭제하지 말 것
3. 확인되지 않은 출처나 사실을 추측해서 지어내지 말 것
4. 내 명시적 승인 없이 메일 발송, 외부 공유, 자동화 변경, 파일 삭제를 실행하지 말 것

[진행 순서]
1단계: 먼저 아무 파일도 수정하지 말고, Orca 봇의 기능과 내 위 폴더들의 구조·평소 작업 스타일을 읽기 전용으로 파악해 줘.
2단계: 파악한 내용을 바탕으로 나에게 맞는 비서실장 규칙(SOUL.md) 초안과 산하 전문 봇 편제표(봇 이름, 역할, 협업 흐름, 폴더 권한)를 종합 제안해 줘. 이때 각 봇의 업무 난이도와 내 구독 환경에 맞춰 추천 AI 모델과 추론 강도(낮음·보통·높음) 및 선정 이유까지 함께 제안해 줘.
3단계: 내가 제안서를 승인하면 산하 봇 생성 제안 카드(Create bot)를 올려 주고, 내가 추천 모델과 추론 강도를 확인해 생성을 완료한 뒤 각 봇의 SOUL.md와 MEMORY.md 세팅까지 일괄 마무리해 줘.

5. 운영할 때 알아 두면 좋은 핵심 원칙 5가지

  1. 1
    비서실장은 지휘만 하고 직접 연주하지 않는다 산하 전문 봇이 갖춰진 뒤에는 비서실장에게 직접 실무 작성을 맡기지 않고 작업 분해·배분·현황 점검만 맡겨야 컨텍스트가 가볍고 전체 팀이 질서 있게 돌아갑니다.
  2. 2
    깊은 1:1 대화가 필요한 업무는 전문 봇과 직접 소통한다 여러 단계가 얽힌 복합 과제는 비서실장에게 맡기되, 호흡이 긴 아이디어나 초안을 다듬는 대화는 해당 전문 봇의 채팅방에서 직접 1:1로 진행하는 편이 자연스럽습니다.
  3. 3
    작성 봇과 검수(레드팀) 봇은 역할을 분리한다 (이종 AI 모델 권장) 결과물을 만드는 봇과 논리적 허점·출처 오류를 비판적으로 점검하는 감수(레드팀) 봇은 별도 봇으로 분리해 두는 편이 좋습니다. 하나의 AI 서비스만 구독 중이라면 같은 모델로 역할을 나누어도 충분히 동작하며, 여유가 된다면 서로 다른 AI 모델(이종 모델)을 배치해 교차 검증하면 편향을 한층 더 줄일 수 있습니다. (수정 재시도는 최대 2회로 제한해 무한 반복을 방지합니다.)
  4. 4
    대화가 길어지면 "새 채팅 시작해 줘"로 정리한다 Home Chat에 대화가 길게 쌓이면 응답이 느려질 수 있습니다. "새 채팅 시작해 줘"라고 말하면 기존 대화는 기록으로 남고, 세팅된 규칙(SOUL.md)과 장기 기억(MEMORY.md)만 깔끔하게 유지된 새 세션이 열립니다. 긴 프로젝트는 별도 채팅방으로 분리해 진행하는 편이 안정적입니다.
  5. 5
    여러 기기에서 함께 쓴다면 (상시 구동 호스트 + 단말기 구조) 일반적으로는 항상 켜져 있는 메인 호스트 1대(데스크톱·맥 미니·클라우드 서버 등)에 봇과 정기 자동화를 두고, 이동 중에는 노트북·휴대폰·태블릿 같은 단말기에서 접속해 지시하는 구조가 가장 깔끔합니다. 만약 데스크톱과 노트북 양쪽에 각각 Orca를 설치해 함께 쓰신다면, 매주 자동 실행되는 정기 스케줄은 메인 호스트 1대에서만 활성화하고 보조 기기에서는 비활성화해 두어야 중복 실행을 막을 수 있습니다.

6. 한눈에 보는 10분 온보딩 역할 분담표

순서 사용자가 직접 할 일 비서실장 1호 봇이 대신 할 일
1 Orca 설치 및 AI 계정 로그인 (대기)
2 1호 봇(비서실장) 딱 1개만 생성 첫 인사 후 대기
3 4장의 프롬프트에 폴더 경로·보유 AI·원하는 업무를 적어 전송 Orca 기능 파악 + 내 작업 공간 읽기 전용 정밀 분석 + 산하 봇 편제표(추천 모델·추론 강도 포함) 제안
4 제안서 검토·승인 후, 모델·추론 강도를 확인하며 Create bot 카드 클릭 각 산하 봇 생성 카드 발송 + 생성 완료 후 SOUL.md·MEMORY.md 일괄 세팅
5 (선택) "Google 연결해 줘" 입력 후 카드 클릭 외부 서비스 연동 안내 및 전체 봇 현황 최종 점검 보고
