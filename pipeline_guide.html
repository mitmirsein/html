수학 기출 포렌식 파이프라인

PDF 문제지를 넣으면 정답·문항·해설·변형·도형·PDF 발행까지 이어지는 흐름을 한눈에 보여줍니다. 이번 개선으로 미적분·확률과 통계까지 더 안정적으로 다루고, 실패 원인도 더 분명하게 설명합니다.
Project Overview

수학 기출 문제를 “풀이”가 아니라 “교안”으로 바꾸는 자동 발행 파이프라인입니다.

이 프로젝트는 기출 PDF나 문항 이미지를 받아 정답, 문제 본문, 도형, 개념 구조, 풀이 흐름, 오답 유도 지점, 변형 대비 문제, 최종 PDF 교안까지 하나의 흐름으로 묶습니다. 목표는 단순히 답을 맞히는 것이 아니라 “왜 이 문제가 이렇게 출제되었는가”, “학생은 어디서 막히는가”, “어떤 원리를 다른 문제로 옮길 수 있는가”를 선명하게 드러내는 것입니다.

교사를 위한 도구 한 문항을 수업 가능한 해설, 질문 흐름, 오답 반박, 변형 대비 자료로 빠르게 정리합니다.
콘텐츠 팀을 위한 공정 OCR, 수식 정제, 도형 검증, PDF 발행, 증거 기록을 반복 가능한 제작 라인으로 만듭니다.
AI를 안전하게 쓰는 방식 모델이 만든 답을 그대로 믿지 않고, 정답 권위값·스키마·증거·게이트로 단계마다 확인합니다.
프로덕션을 위한 품질 관리 결과물이 언제, 어떤 입력과 엔진 상태에서 만들어졌는지 기록해 나중에 다시 검증할 수 있게 합니다.
정답 데이터 정제된 문제 본문 개념·풀이 구조 도형·그래프 변형 대비 문제 마크다운 교안 PDF 교재 검증 리포트
이번 버전의 핵심은 “더 많이 그리는 것”이 아니라 “틀린 것을 더 빨리 알아차리는 것”입니다. 기하 도형만 조심스럽게 다루던 수준에서 벗어나, 미적분 그래프와 확률·통계 다이어그램까지 다루는 기반을 마련했습니다. 또한 PDF가 깨지거나, 변형 문제가 원본을 베끼거나, 중간 작업이 이전 결과를 지우는 상황을 더 명확히 잡아냅니다.
이번 개선으로 넓어진 분석 범위
  • 미적분 그래프
    다항식, 유리함수, 제곱근, 지수·로그, 삼각함수를 안전한 파서로 읽고 정의역 안에서 곡선을 샘플링합니다. 끊어지는 지점과 화면 밖으로 나가는 값도 기록합니다.
    function-curves SVG/TikZ
  • 확률·통계 도표
    벤다이어그램, 이산분포 막대그래프, 정규분포 음영, 시행 트리, 상태 전이 격자를 템플릿으로 그립니다. 확률의 합과 구간 순서도 함께 검사합니다.
    probability-diagrams 확률합 1
  • 라벨 겹침 완화
    점 이름과 수식 라벨이 선분·곡선·다른 글자와 겹치지 않도록 비용 함수를 사용해 배치합니다. 같은 입력이면 같은 그림이 나오도록 결정론적으로 동작합니다.
    label-optimizer byte-identical

전 영역 확장

기하뿐 아니라 미적분 함수 그래프, 확률·통계 도표까지 설명 자료로 만들 수 있는 기반을 갖췄습니다.

PDF 실패 원인 표시

긴 수식, 지원하지 않는 LaTeX 명령, 치명적 컴파일 로그를 구조화해 어디서 깨졌는지 보여줍니다.

중단 후 이어가기

작업이 중간에 실패해도 완료된 단계는 건너뛰고 실패 지점부터 다시 시작할 수 있는 구조를 마련했습니다.

1
1단계: 정답 시딩 (PDF Ingest Seeding)
GT확보 / OCR대기

기출 PDF 파일로부터 대상 학년도 및 시험 정보를 매핑하고, 데이터베이스에 해당 문항을 고유 케이스로 등록하여 빈 껍데기(Shell)를 형성하는 단계입니다.

동작 및 산출 데이터
  • 이미지 렌더링
    pdftoppm을 가동하여 원본 PDF 페이지를 고해상도(150dpi) PNG 이미지로 렌더링합니다.
  • 정답 매칭
    해설지 파싱 및 분석을 통해 30개 기출 문항의 정답(Ground Truth)을 매칭합니다.
  • 데이터베이스 인입
    데이터베이스 저장소 어댑터에 최초의 문항 데이터 슬롯을 생성합니다.
2
2단계: 이미지 절단 (Cropping)
GT확보 / CROP완료 / OCR대기

전체 시험지 페이지 이미지에서 불필요한 테두리를 버리고 개별 문항 영역만을 바운딩 박스로 정확히 잘라내어 독립된 이미지 자산으로 확보하는 단계입니다.

동작 및 산출 데이터
  • 바운딩 템플릿
    표준 시험지 레이아웃(A3 2단 구성) 기준의 영역 좌표 분할 템플릿을 적용합니다.
  • 이미지 절단
    macOS 네이티브 sips 명령어를 스크립트 내부에서 일괄 실행합니다.
  • 개별 자산 확보
    문항별 잘려나간 개별 이미지 파일들을 자산 폴더에 성공적으로 적치합니다.
    figures/source-01.png
3
3단계: 원시 OCR 결합 (Raw OCR Ingest)
OCR원문확보 / 정제대기

잘려나간 문항 이미지로부터 발문 텍스트를 기계적으로 추출하여, 시스템이 읽을 수 있는 대략적인 텍스트 데이터를 확보하는 단계입니다.

동작 및 산출 데이터
  • OCR 엔진 구동
    로컬 Tesseract OCR(수식, 한글, 영문 라이브러리 탑재) 엔진을 호출합니다.
  • 품질 자동 판정
    추출된 한글 비율과 문자 패턴을 분석하여 기계적 품질 보고서를 생성합니다.
  • 원시 텍스트 결합
    판독된 날것의 수학 기호와 원시 텍스트를 문항 케이스 메타데이터에 안착시킵니다.
    ocr/raw-tesseract.txt
4
4단계: 수식 클리닝 및 승격 (Text Cleaning & Promotion)
OCR정제승격 / 실행대기

기계적 OCR 단계에서 깨진 수식 기호를 수학적으로 정확한 LaTeX 코드로 수동/자동 검수 교정하고 보기 선지를 구조화하여 엔진 분석 준비를 끝마치는 단계입니다.

동작 및 산출 데이터
  • LaTeX 수식 복원
    에이전트 검수를 가동해 무결하고 엄격한 표준 LaTeX 수식 표기법으로 보정합니다.
  • 구조적 정보 파싱
    5지선다 보기 배열 및 정오표 지문, 합의 조건 상자 데이터를 정밀 매핑합니다.
    choices boxed_statements
  • 골든 인덱스 승격
    교정된 마크다운/수식 데이터를 저장 및 승격하고 골든 데이터셋 인덱스를 갱신합니다.
    case.json
5
5단계: 문제 분석 (기하 도형 분석도 가능)
분석완료 / 솔루션대기

승격된 기출 문항의 수학적 출제 원리와 개념 연쇄망(DAG)을 철학적·논리학적 구조로 해체하여 분석하고, 도형 문항의 경우 기하학적 형상을 정밀하게 피팅하는 심층 분석 단계입니다.

동작 및 산출 데이터
  • 개념과 조건 지도
    문항 조건과 수학적 개념들의 결합을 삼단논법 체계로 분해하여 근원(archai) 의존성 그래프로 인덱싱합니다.
    foundation.archai_dag 품질개선: 조건 충돌을 사전에 잡아 잘못된 변형을 크게 줄임
  • 막히는 지점 기반 힌트
    발문에서 답으로 유도하는 인과 과정을 질문 연쇄 노드로 설계합니다.
    Socratic_Hint_Query 품질개선: 학생이 막히는 지점을 더 잘 짚는 힌트 생성
  • 정확한 도형 엔진
    완벽한 상사비와 점/선 제약식을 수치 솔버로 피팅하여 모순 오차를 0으로 만듭니다.
    geometry_spec geometry-certificate 품질개선: 도형 겹침과 PDF 오류 원인을 구조화해 빠르게 수정
6
6단계: 변형 시뮬레이션 및 오케스트레이션 (Variant Ingest)
변형완료 / 컴파일대기

분석된 수학적 인과 구조와 오개념 요소를 흔들어, 본래의 출제 의도를 변별하면서도 조건이 세련되게 변형된 실전용 변형 문항 및 해설 단계를 생성하는 단계입니다.

동작 및 산출 데이터
  • 변형 치수 시뮬레이션
    기하학적 상사비와 불변 성질을 유지한 한도 내에서 최적의 변이 조건을 형성합니다.
  • 해설 오케스트레이션
    00~04 생성 에이전트를 차례로 구동하여 단계별 변형 풀이 과정을 자동 수립합니다.
    variant_solution
  • 위생 필터링 검수
    수식 문법 오류, 부자연스러운 한글 문장 표현을 사전에 전수 검수합니다.
7
7단계: 마크다운(MD) 및 PDF 발행 (Markdown & PDF Publish)
발행완료

정제 및 변형된 수학 문항 데이터를 마크다운(MD) 소스로 취합하고, Noto Serif 서체 환경 하에 XeLaTeX 컴파일러를 구동하여 최종 PDF 교안을 발행하는 단계입니다.

동작 및 산출 데이터
  • A4 인쇄 레이아웃
    Noto Serif 서체 및 여백 제어 패키지를 활용한 1단 교재 레이아웃을 형성합니다.
  • 다이어그램 벡터 드로잉
    TikZ 컴파일러 또는 SVG 변환기를 작동해 정밀 기하 도형 벡터 렌더링을 그립니다.
  • PDF 컴파일
    XeLaTeX 빌더 및 배포 준비 테스트 통과 후 최종 PDF 교재를 배포용 폴더에 출력합니다.
    output/
프로젝트 신뢰 경계 통제 프레임워크 (horos)
통제 가동 중

이 수학 기출 포렌식 파이프라인은 AI 에이전트의 자기 기만(Hallucination)을 막고 계약 무결성을 외부에서 강제하는 가드레일 프레임워크인 horos의 5대 강제 정책 하에 통제됩니다.

파이프라인 내 horos의 5대 실질 강제 행위
  • ① 기름값 사전 검사기
    1단계 가동 전 디스크 여유 공간이 부족하면 불필요한 API 요금이 발생하지 않도록 실행을 즉시 셧다운(Pre-flight)시킵니다.
    PreflightError engine:doctor
  • ② 짝퉁 변형 문제 적발기
    5단계와 6단계 사이에서 AI가 본문 문투만 바꾸거나 숫자만 교체하여 제출한 가짜 변형 문항을 자동 검출하고 차단(block)합니다.
    ENGINE-SEM-NUMERIC-CLONE Semantic Diff
  • ③ 기하학적 붕괴 감지기
    수치 최적화 솔버를 통해 변형 기하 도형의 모든 수치적 제약 오차를 계산하여, 선이 찌그러지거나 레이아웃이 겹치는 도형 생성을 금지합니다.
    ENGINE-GEOM-LAYOUT-FAIL Geometry Certificate
  • ④ 야바위 풀이 감별사
    논리 단계의 인과 의존성 그래프(Kahn 위상 정렬)를 역추적 검산하여, 원리 도약이나 모순이 있는 해설의 배포 후보 승인을 완강히 거부합니다.
    ENGINE-PROOF-ANSWER-MISMATCH Proof Gate
  • ⑤ 신선도 라벨 감시관
    7단계 최종 배포 시, SHA-256 해시 대조를 거쳐 이전에 검증 완료된 결과물 파일을 수동으로 임의 변조한 흔적을 잡아내 차단(release-strict)합니다.
    06.run-evidence.json ENGINE-EVIDENCE-STALE
  • 정본 레포지토리
    에이전트 훅 및 신뢰 경계 통제 정본 소스 레포지토리 주소입니다.
    https://github.com/mitmirsein/horos

생산 품질이 좋아졌다는 뜻

이번 개선은 화면을 더 화려하게 만든 작업이 아니라, 실제 운영에서 문제를 덜 만들고 더 빨리 고치게 하는 작업입니다.

  • 틀린 그림을 덜 냅니다. 도형, 원뿔곡선, 함수 곡선, 통계 도표가 각각 검증 가능한 계약을 갖습니다.
  • PDF가 왜 깨졌는지 말합니다. 긴 인라인 수식은 display 수식으로 올리고, 치명적 로그와 지원하지 않는 명령을 구체적으로 표시합니다.
  • 변형 문제의 베끼기를 잡습니다. 숫자만 바꾸거나 원본 구조를 거의 복제한 문항은 Mutation Lab과 Semantic Gate에서 걸러냅니다.
  • 결과물의 출처를 남깁니다. 실행 당시의 엔진 코드, 설정, 프롬프트, 케이스 내용을 해시로 기록해 나중에 바뀐 파일과 구분합니다.
  • 실패 후 다시 시작할 수 있습니다. 완료된 단계는 건너뛰고 실패한 단계부터 재개하는 오케스트레이션 계약을 갖습니다.
