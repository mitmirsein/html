수학 기출 포렌식 파이프라인

PDF 문제지 인입부터 수학적 분석 및 변형 교안 생성, 그리고 조판을 거쳐 고품질 PDF 교재 발행에 이르는 전 과정을 소개합니다.
1
1단계: 정답 시딩 (PDF Ingest Seeding)
GT확보 / OCR대기

기출 PDF 파일로부터 대상 학년도 및 시험 정보를 매핑하고, 데이터베이스에 해당 문항을 고유 케이스로 등록하여 빈 껍데기(Shell)를 형성하는 단계입니다.

동작 및 산출 데이터
  • pdftoppm을 사용한 PDF 원본의 고해상도(150dpi) 이미지 렌더링
  • 해설지 분석을 통한 30개 기출 문항의 정답(Ground Truth) 수집 및 매칭
  • 데이터베이스 저장소 어댑터에 최초 슬롯 생성
2
2단계: 이미지 절단 (Cropping)
GT확보 / CROP완료 / OCR대기

전체 시험지 페이지 이미지에서 불필요한 테두리를 버리고 개별 문항 영역만을 바운딩 박스로 정확히 잘라내어 독립된 이미지 자산으로 확보하는 단계입니다.

동작 및 산출 데이터
  • 표준 시험지 레이아웃(A3 2단 구성) 기준 좌표 좌표(x, y, w, h) 분할 템플릿 사용
  • macOS 네이티브 그래픽 명령어 sips를 스크립트 내부에서 일괄 가동
  • 문항별 개별 이미지 자산(figures/source-01.png) 보관소 생성
3
3단계: 원시 OCR 결합 (Raw OCR Ingest)
OCR원문확보 / 정제대기

잘려나간 문항 이미지로부터 발문 텍스트를 기계적으로 추출하여, 시스템이 읽을 수 있는 대략적인 텍스트 데이터를 확보하는 단계입니다.

동작 및 산출 데이터
  • 로컬 Tesseract OCR(equ, kor, eng 라이브러리 탑재) 구동
  • 추출 텍스트의 한글 비율 분석을 통한 기계적 품질(quality) 판정 및 보고서 생성
  • 추출된 날것의 수식을 ocr/raw-tesseract.txt에 결합
4
4단계: 수식 클리닝 및 승격 (Text Cleaning & Promotion)
OCR정제승격 / 실행대기

기계적 OCR 단계에서 깨진 수식 기호를 수학적으로 정확한 LaTeX 코드로 수동/자동 검수 교정하고 보기 선지를 구조화하여 엔진 분석 준비를 끝마치는 단계입니다.

동작 및 산출 데이터
  • LLM(에이전트)이 개입하여 맥락에 부합하는 무결한 LaTeX 문법으로 수식 기호 복원
  • 5지선다의 보기 리스트(choices) 및 조건문(boxed_statements) 매핑
  • 교정 데이터를 case.json에 저장 후 승격하고 골든 인덱스 재빌드
5
5단계: 문제 분석 (기하 도형 분석도 가능)
분석완료 / 솔루션대기

승격된 기출 문항의 수학적 출제 원리와 개념 연쇄망(DAG)을 구성하고, 도형 문항의 경우 기하 제약 조건을 수치 솔버로 피팅하는 심층 분석 단계입니다.

동작 및 산출 데이터
  • 도형 문항의 기하학적 형상과 점/선 제약 수치 명세(geometry_spec) 설계
  • 도형 최적화 솔버를 구동하여 변수 피팅 및 잔차 검증 수행(geometry-certificate)
  • 문항의 출제 원리와 개념 연쇄망을 구성하는 의도 그래프(archai_dag) 형성
6
6단계: 변형 시뮬레이션 및 오케스트레이션 (Variant Ingest)
변형완료 / 컴파일대기

분석된 수학적 인과 구조와 오개념 요소를 흔들어, 본래의 출제 의도를 변별하면서도 조건이 세련되게 변형된 실전용 변형 문항 및 해설 단계를 생성하는 단계입니다.

동작 및 산출 데이터
  • 기하학적 상사(Similarity) 및 불변 법칙(Invariants)을 유지한 변형 치수 생성
  • 00~04 생성 오케스트레이터를 가동하여 단계별 변형 해설(variant_solution) 자동 수립
  • 한국어 평서문 및 수식 위생 필터 검수 자동 적용
7
7단계: 마크다운(MD) 및 PDF 발행 (Markdown & PDF Publish)
발행완료

정제 및 변형된 수학 문항 데이터를 마크다운(MD) 소스로 취합하고, Noto Serif 서체 환경 하에 XeLaTeX 컴파일러를 구동하여 최종 PDF 교안을 발행하는 단계입니다.

동작 및 산출 데이터
  • Noto Serif CJK KR 서체 및 A4 교재 스타일 레이아웃 기반 조판 환경 세팅
  • TikZ 또는 SVG 벡터 엔진을 이용한 정밀 기하 도형 다이어그램 벡터 드로잉
  • 컴파일러 구동 및 조판 테스트 하네스 검수 통과 후 최종 output/ PDF 생성
